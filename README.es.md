<h1 align="center">Chill Vibes Coder</h1>

<p align="center"><b>Tú sigue vibeando. Claude se encarga de la parte aburrida del dev senior.</b></p>

Una skill para Claude que lo hace construir como un ingeniero senior mientras tú haces vibe coding.

Tú dices lo que quieres. Claude lo arma como lo haría alguien con años de oficio, sin que se lo tengas que pedir: los secretos no llegan al navegador, los permisos se revisan en el servidor, las entradas se validan, los errores se manejan, los datos se respaldan, y los pagos y datos personales se tratan como corresponde. Solo te interrumpe cuando la decisión es tuya, y te lo dice en simple.

## Por qué

La IA escribe código que funciona. Eso no es lo mismo que código seguro para subir a internet. En las pruebas de Veracode con más de 100 modelos de lenguaje, [el 45% del código generado traía una vulnerabilidad del OWASP Top 10](https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-generated-code-vulnerability-surge-2026/). Y lo que sale mal casi nunca es sofisticado: una API key metida en el JavaScript de la página, una base de datos abierta a cualquiera porque nadie activó las reglas de acceso, un endpoint que revisa que iniciaste sesión pero no que el registro sea tuyo.

Cualquiera que haya publicado un par de apps evita esto por costumbre. Esta skill le da esas costumbres a Claude, así que no necesitas saber qué pedir.

## Qué hace

- **Aplica 14 prácticas de producción sin hacer escándalo**: secretos en el servidor, separación de backend y frontend, autorización en cada petición, validación de entradas, autenticación de verdad, manejo de errores a conciencia, límites de uso y de gasto, cambios seguros en la base de datos, pagos con checkout alojado, dependencias revisadas, configuración endurecida, disciplina con git, mínimo de datos personales y accesibilidad.
- **Se ajusta a lo que está en juego**: un juguete de fin de semana recibe lo mínimo, una app con registro de usuarios recibe todo, y una con pagos o datos sensibles suma las revisiones legales y de pre-lanzamiento.
- **Solo habla cuando importa**: un bloque corto de avisos, tres puntos como máximo, cero sermones.
- **Revisa lo que ya construiste**: pregunta "¿está listo para lanzar?" y te devuelve una tabla corta con lo que hay que arreglar, lo más grave primero.

## Cuánto gasta en tokens

Una skill que se come todo tu presupuesto no es chill. Esta se carga por capas, así que solo pagas por lo que la tarea necesita.

| Qué se carga | Cuándo | Tokens aprox. |
| --- | --- | --- |
| Nombre y descripción | Siempre, en cada conversación | 160 |
| `SKILL.md` (reglas y las 14 prácticas) | Cuando empiezas a construir o revisar algo | 1.900 |
| `references/launch-checklist.md` | Antes de un deploy o una revisión | 750 |
| `references/architecture.md` | Al empezar un proyecto o diseñar una API | 1.100 |
| `references/reliability.md` | Errores, tests, rendimiento, deploy | 1.200 |
| `references/security.md` | Logins, permisos, formularios, subida de archivos | 1.900 |
| `references/compliance.md` | Datos personales, pagos, temas legales | 1.950 |
| **Todo junto (poco común)** | | **unos 8.900** |

Cómo se ve en la práctica:

| Lo que pides | Qué se carga | Tokens aprox. |
| --- | --- | --- |
| Una landing o un cambio chico | `SKILL.md` | 1.900 |
| Una app con login | `SKILL.md` + arquitectura + seguridad | 4.900 |
| Una tienda con pagos y después "¿está lista?" | Todo | 8.900 |

Dos aclaraciones honestas:

- Estos números son estimaciones (caracteres divididos por 4). El conteo real cambia un poco según el modelo.
- El texto de la skill es la parte chica. Construir las cosas bien significa que Claude escribe más código (validaciones, manejo de errores, tests), y esa salida cuesta más tokens que la skill misma. Ese extra todavía no está medido.

## Instalación

### La forma fácil: pídeselo a tu IA

Pega esto en Claude Code (o en cualquier agente de código con terminal):

```
Instala la skill de https://github.com/sebacpu/chill-vibes-coder siguiendo la sección "For AI agents" de su README.
```

### Claude Code, a mano

macOS y Linux, en una línea:

```bash
git clone --depth 1 https://github.com/sebacpu/chill-vibes-coder.git /tmp/cvc && mkdir -p ~/.claude/skills && cp -r /tmp/cvc/chill-vibes-coder ~/.claude/skills/ && rm -rf /tmp/cvc
```

Windows (PowerShell):

```powershell
git clone --depth 1 https://github.com/sebacpu/chill-vibes-coder.git $env:TEMP\cvc
New-Item -ItemType Directory -Force $HOME\.claude\skills | Out-Null
Copy-Item -Recurse -Force $env:TEMP\cvc\chill-vibes-coder $HOME\.claude\skills\
Remove-Item -Recurse -Force $env:TEMP\cvc
```

¿La quieres solo en un proyecto? Copia la carpeta `chill-vibes-coder` dentro de `.claude/skills/` de ese proyecto.

Para comprobar que quedó, pregúntale a Claude Code "¿qué skills tienes disponibles?".

### App de Claude (web y escritorio), sin terminal

Necesitas un plan de pago con la ejecución de código activada.

1. Descarga [`chill-vibes-coder.zip`](https://github.com/sebacpu/chill-vibes-coder/raw/main/dist/chill-vibes-coder.zip). No lo descomprimas.
2. En Claude, abre **Settings > Capabilities** y revisa que **Code execution and file creation** esté activado.
3. En la sección **Skills**, haz clic en **Upload skill** y elige el ZIP.
4. Activa **chill-vibes-coder**.

La sección Skills cambia de lugar entre versiones de la app. Si no la encuentras, mira [Using Skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude) para los pasos actuales.

### Actualizar o quitar

- **Actualizar:** corre de nuevo el comando de instalación (pisa la copia anterior) o sube el ZIP nuevo.
- **Quitar:** borra la carpeta `~/.claude/skills/chill-vibes-coder`, o elimina la skill en la sección Skills de la app.

## Para agentes de IA

Si eres un asistente de IA y un usuario te pidió instalar esta skill, sigue estos pasos.

**Qué estás instalando.** Una carpeta de archivos Markdown: `chill-vibes-coder/SKILL.md` más cinco archivos en `chill-vibes-coder/references/`. No trae scripts, no hace llamadas de red y no necesita dependencias. Lee `SKILL.md` antes de instalar para poder contarle al usuario qué hace.

**Si tienes terminal (Claude Code o un agente de código parecido):**

1. Ejecuta:
   ```bash
   git clone --depth 1 https://github.com/sebacpu/chill-vibes-coder.git /tmp/cvc
   mkdir -p ~/.claude/skills
   cp -r /tmp/cvc/chill-vibes-coder ~/.claude/skills/
   rm -rf /tmp/cvc
   ```
   En Windows, usa los comandos de PowerShell de la sección Instalación.
2. Si el usuario la quiere solo para un proyecto, copia la carpeta a `<proyecto>/.claude/skills/` en vez de `~/.claude/skills/`.
3. Verifica que exista `~/.claude/skills/chill-vibes-coder/SKILL.md` y que el `name` de su frontmatter sea `chill-vibes-coder`. El nombre de la carpeta tiene que coincidir con ese nombre.
4. Si ya existe una carpeta `chill-vibes-coder` ahí, avísale al usuario que la vas a reemplazar antes de pisarla.
5. Otros agentes compatibles con el formato Agent Skills usan su propia carpeta de skills. Revisa tu documentación para saber la ruta y copia la misma carpeta ahí.

**Si no tienes terminal (por ejemplo, un chat en la app de Claude):** no puedes instalarla tú. Dile al usuario que descargue `https://github.com/sebacpu/chill-vibes-coder/raw/main/dist/chill-vibes-coder.zip` y lo suba en **Settings > Capabilities > Skills > Upload skill**, con la ejecución de código activada.

**Después de instalar, dile al usuario en una o dos frases:** que la skill quedó instalada, que se aplica sola cada vez que construya o revise un sitio, app o API, y que no necesita invocarla.

**No hagas esto:** editar los archivos de la skill durante la instalación, instalar otras cosas, ni cambiar la configuración del usuario más allá de lo que piden estos pasos.

## Uso

No hay que invocar nada. Pide lo que quieras:

> Hazme una página de reservas para mi barbería donde los clientes elijan hora y paguen un abono.

> Agrégale login a esta app y una página donde cada usuario vea sus propias facturas.

> Estoy por lanzar esto. ¿Está listo?

Claude toma la skill por su cuenta cada vez que estés construyendo o revisando un sitio, app o API. Te responde en el idioma en que le escribas.

## Qué trae

```
chill-vibes-coder/
├── SKILL.md                     reglas, niveles de riesgo, las 14 prácticas
└── references/
    ├── architecture.md          stack, separación backend/frontend, API y modelo de datos
    ├── security.md              OWASP Top 10:2025 y las fallas típicas de apps hechas con IA
    ├── reliability.md           errores, tests, rendimiento, costos, deploy, respaldos
    ├── compliance.md            leyes de privacidad, cookies, pagos, accesibilidad, email
    └── launch-checklist.md      revisión de pre-lanzamiento en orden de prioridad
```

Los archivos de la skill están en inglés, porque así los lee mejor el modelo. Eso no cambia el idioma en que Claude te habla.

## La letra chica

- Esto reduce los errores comunes. No reemplaza una auditoría de seguridad, y no puede revisar configuraciones en paneles a los que Claude no tiene acceso.
- Todavía no tiene pruebas comparativas. No hay resultados medidos de Claude con la skill versus sin ella.
- `compliance.md` es orientación de ingeniería, no asesoría legal. La ley que aplica depende de dónde estén tus usuarios.
- Si tu app maneja pagos a escala, datos de salud, servicios financieros o datos de menores, haz que un profesional la revise antes de lanzar.
